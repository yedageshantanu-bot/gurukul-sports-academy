# Gurukul Sports Academy — CRM & Management System

Complete Academy Management System tailored for **Gurukul Sports Academy**, managing students, sports batches, attendance, fee collection & receipts, and WhatsApp communications.

## 📁 Project Structure

```
GURUKUL SPORTS ACADEMY/
├── backend/          # Node.js + Express + TypeScript Backend API
│   ├── src/          # Routes, Controllers, Services, Middlewares
│   ├── migrations/   # Database schemas and migrations
│   └── package.json
├── frontend/         # React 18 + Vite + Tailwind CSS + Lucide Icons
│   ├── src/          # Pages (Dashboard, Students, Batches, Fees, Attendance, Settings)
│   ├── public/       # Static assets & icons
│   └── package.json
└── README.md
```

## 🚀 Getting Started

### 1. Backend Setup
```bash
cd backend
npm install   # (Already installed)
npm run dev   # Starts backend on http://localhost:10000
```

### 2. Frontend Setup
```bash
cd frontend
npm install   # (Already installed)
npm run dev   # Starts frontend on http://localhost:3000
```
